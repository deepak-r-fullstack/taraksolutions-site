AgentGuard

Live demo

Lets AI agents work on real company systems, with a person in charge. Every action is checked against the company's rules, risky ones wait for a manager, everything is recorded, and mistakes can be undone with one click.

  • Rules are checked by plain code, so an AI can never talk its way into an approval.
  • Safe against double clicks and retries: twenty Undo clicks at once undo exactly once.
  • Every step recorded: which agent, for whom, which rule, who approved.

React, TypeScript, Node.js, Express, MongoDB. 50 automated tests.

AgentReplay

Live demo

Records every step of an AI run, so when something goes wrong you can see exactly where, try a fix, and keep the failed run as a test.

  • Replay a run on a timeline and see what went in and what came out at each step.
  • Fork any step with a changed prompt or model. Only the AI steps run again; tools are simulated, so nothing real happens.
  • Save a failed run as a test, then run every test after you change the model.

React, Node.js, Express, MongoDB. Also a small npm package with no runtime dependencies. The free demo can take about a minute to wake up on the first visit.
